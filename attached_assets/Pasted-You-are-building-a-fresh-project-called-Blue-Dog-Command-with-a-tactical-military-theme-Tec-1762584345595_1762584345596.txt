## Backend Requirements
Implement REST JSON endpoints:

GET /api/status
- returns { directives: {total, active, completed}, notices: {upcomingCount}, lastUpdated }

Directives (tasks)
- GET /api/directives?status=all|active|completed&priority=low|med|high
- POST /api/directives  body: { title, notes?, priority: 'low'|'med'|'high', dueAt?: ISO }
- PATCH /api/directives/:id  body: partial fields (title, notes, priority, dueAt, completed:boolean)
- DELETE /api/directives/:id

Op Notices (reminders)
- GET /api/notices?from&to (ISO strings)
- POST /api/notices  body: { title, notes?, at: ISO, repeat?: 'none'|'daily'|'weekly'|'monthly' }
- PATCH /api/notices/:id  (title, notes, at, repeat)
- DELETE /api/notices/:id

Data model (SQLite recommended):
- directives: id (text uuid), title (text), notes (text), priority (text), due_at (text nullable), completed (int), created_at (text), updated_at (text)
- notices: id (text uuid), title (text), notes (text), at (text ISO), repeat (text), created_at (text), updated_at (text)

Seed: create 3 sample directives (low/med/high) and 2 sample notices (today+2h, tomorrow 0900).
